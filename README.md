## Functies

| Functie | Omschrijving                                                                               |
|---|--------------------------------------------------------------------------------------------|
| **TL (Hotkey)** | Stuur jouw coördinaten in de chat door het indrukken van de hotkey.                        |
| **`/follow <naam>`** | Volg de live locatie van een Kingdom-genoot zodat je altijd weet waar je teamgenoten zijn. |
| **`/unfollow <naam>`** | Stop met het volgen van een specifieke speler.                                             |
| **`/unfollowall`** | Stop met het volgen van alle spelers.                                                      |
| **1.8 Zwem Animatie** | Kies tussen de klassieke 1.8 zwemstijl of de moderne animatie.                             |
| **Reparatiekosten** | Toont hoeveel levels een reparatie kost direct op het tooltip van een item.                |
| **Cooldown Displays** | Live cooldown-indicatoren van een aantal items.                                            |
| **Auto Follow** | Volg automatisch een speler zodra zij een TL bericht sturen.                               |
